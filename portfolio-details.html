Project Overview

This project is a web-based e-commerce system developed to support online product browsing, ordering, and delivery management. It was designed to provide a simple, user-friendly, and efficient shopping experience for customers while also helping administrators manage products, orders, and delivery information.

The system was developed using HTML, CSS, JavaScript, PHP Laravel, and MySQL. Through this project, I improved my skills in full-stack web development, database design, responsive user interface development, and system functionality planning.

Key Features

Responsive Design

The website is designed to work smoothly on desktop, tablet, and mobile devices for a better user experience.

Secure User Access

The system supports secure login, user roles, and protected access for customers, administrators, and delivery staff.

Order Management

Users can place orders and track their status, while administrators can manage products, payments, and delivery progress.

Database Integration

The project uses MySQL for storing and managing product data, user accounts, and transaction information efficiently.
